## Staged Implementation Roadmap

1. **Stage 1: Page Structure Only** — Section scaffolding in order from `prd.md` (Headings & placeholders only. No styling, no components).
2. **Stage 2: Visual Design** — Apply colors, typography, spacing, and hierarchy from `design.md`. (No real content, no components).
3. **Stage 3: Real Content Integration** — Replace placeholders with verified data from `Profile (1).pdf` only. Report any missing data without filler text.
4. **Stage 4: Components & Interactivity** — Action buttons, copy email with toast, smooth navigation, interactive cards.
5. **Stage 5: Responsive Polish** — 12-col desktop grid, 8-col tablet layout, single-column mobile stack with persistent contact dock.
6. **Stage 6: Final Verification & Audit** — Accessibility, contrast, responsiveness, and final sign-off.
