## Brand & Style

This design system expresses the visual and structural identity of an ambitious, analytical Computer Science & Engineering student specializing in AI/ML, Python, and practical systems engineering. The design language avoids hyperbole, buzzword clutter, and superficial flash. Instead, it projects intellectual rigor, technical transparency, and genuine curiosity.

The style synthesizes **Technical Minimalism** with **Subtle Tactile Glassmorphism**. Dark slate and midnight navy surfaces establish a tranquil, high-focus studio environment. Clean, crisp borders and monospaced data accents convey code-level precision, while purposeful vibrant blue accents draw attention to shipped projects, architecture decisions, and core technical proficiencies.

### Emotional Response
- **Credible & Rigorous:** Engineering depth conveyed through precision alignment, disciplined spacing, and monospaced code elements.
- **Calm & Unhurried:** Generous negative space that allows complex technical projects to be inspected without cognitive fatigue.
- **Forward-Looking & Pragmatic:** An authentic student mindset grounded in foundational computer science principles and active curiosity toward modern machine learning architectures.

## Colors

The palette operates in a default dark mode, structured around deep atmospheric navy-slate foundations, graduated text hierarchy, and focused electric blue interactions.

### Palette Architecture
- **Canvas Base (`#0B0F19`):** Deepest void layer for full-screen viewport grounding.
- **Surface Elevation 1 (`#111827`):** Structural layout containers, navigation panels, and section backdrops.
- **Surface Elevation 2 (`#1E293B`):** Cards, project frames, code snippets, and modal surfaces.
- **Surface Elevation 3 (`#334155`):** Hover states, dividers, input borders, and badge outlines.
- **Primary Accent (`#3B82F6`):** Primary actions, callouts, active timeline markers, and focus states.
- **Secondary Accent (`#60A5FA`):** Interactive text links, metric emphasis, and tag highlights.
- **Tertiary Accent (`#38BDF8`):** AI/ML parameter callouts, graph highlights, and computational accents.
- **Text High-Contrast (`#F8FAFC`):** Primary headlines, code blocks, and primary labels.
- **Text Medium-Contrast (`#94A3B8`):** Body narrative, architecture summaries, and inactive navigation items.
- **Text Low-Contrast (`#64748B`):** Metadata, commit hashes, timestamps, and secondary captions.
- **Subtle Accent Glow (`rgba(59, 130, 246, 0.12)`): Ambient backdrops behind prominent featured builds.

## Typography

The typography strategy builds deliberate tension between geometric humanist headlines, utilitarian body copy, and precision monospaced accents.

- **Headlines (Plus Jakarta Sans):** Modern and approachable with tight letter-spacing for commanding section title anchors. It eliminates the dryness of typical academic resumes.
- **Body Text (Inter):** Highly legible, neutral workhorse for technical descriptions, architecture walkthroughs, and personal intros.
- **Technical Accents & Metadata (JetBrains Mono):** Applied strictly to code snippets, skill tags, metrics, performance statistics, and section category prefixes (e.g., `01 // FOCUS_AREAS`).
- **Vertical Rhythm:** Paragraphs are capped at a maximum width of 68 characters (`68ch`) to maintain optimal reading cadence on high-resolution displays.

## Layout & Spacing

The portfolio employs a structured 12-column fluid grid system bounded by a max container width of `76rem` (1216px) with an 8px modular baseline scale.

### Layout Rhythm
- **Page Sections:** Generous vertical rhythm utilizing `space-4xl` (96px) on desktop and `space-2xl` (48px) on mobile between major content blocks (`Introduction`, `Focus Areas`, `Core Skills`, `Projects`, `What I'm Seeking`, `Contact`).
- **Card Internals:** Internal padding strictly maintains `space-lg` (24px) on desktop and `space-md` (16px) on small screens.
- **Grid Allocations:**
  - **Desktop (>= 1024px):** 12 columns, 24px gutters, 32px outer safe margin. Featured projects span 6 or 12 columns; skills cards span 4 columns.
  - **Tablet (768px - 1023px):** 8 columns, 16px gutters, 24px outer safe margin. Projects transition to stacked 8-column layouts.
  - **Mobile (< 768px):** 4 columns, 16px gutters, 16px outer safe margin. Strict single-column stack with condensed vertical padding.

## Elevation & Depth

Visual hierarchy is constructed through tonal surface staging complemented by low-contrast borders, rather than heavy skeuomorphic drop shadows.

- **Base Layer:** `#0B0F19` with a subtle radial gradient mask (`rgba(59, 130, 246, 0.04)`) at the hero viewport to create depth without distraction.
- **Resting Layer (Surface Cards):** `#111827` filled with a single-pixel ghost border (`1px solid #1E293B`).
- **Elevated / Focused Cards:** `#1E293B` background with subtle hairline stroke (`1px solid rgba(96, 165, 250, 0.25)`).
- **Soft Accent Diffusions:** When highlighting hero projects or critical CTAs, elements introduce a soft, deep ambient glow: `0 12px 32px -8px rgba(11, 15, 25, 0.8), 0 0 24px -4px rgba(59, 130, 246, 0.15)`.
- **Modals and Overlays:** `#111827` backed with `backdrop-filter: blur(12px)` and `#1E293B` borders.

## Shapes

The design system adopts a soft, disciplined shape profile (`roundedness: 1`). The aesthetic retains clean architectural lines and engineering clarity without aggressive sharp edges or cartoonishly bulbous shapes.

- **Standard Elements (Buttons, Inputs, Badges):** `0.25rem` (4px) to `0.375rem` (6px) corner radii.
- **Containers & Project Cards:** `0.5rem` (8px) corner radius for structural stability.
- **Technical Chips & Pill Indicators:** `0.25rem` (4px) corner radius with monospaced typography, reinforcing a terminal or data-inspector feel over consumer-social styling.

## Components

### Buttons
- **Primary:** `#3B82F6` solid fill, `#F8FAFC` text, `font-family: JetBrains Mono`, semibold 13px, 4px corner radius. On hover: `#60A5FA` fill with zero vertical lift, preserving spatial predictability.
- **Secondary / Outline:** Transparent fill, `1px solid #334155` border, `#F8FAFC` text. On hover: border transitions to `#60A5FA`, background to `rgba(59, 130, 246, 0.08)`.
- **Tertiary / Ghost:** No border, `#94A3B8` text. On hover: `#F8FAFC` text and `rgba(255, 255, 255, 0.04)` fill.

### Technical Chips & Skill Badges
- **Architecture:** Compact height (26px), horizontal padding of 10px.
- **Styling:** Background `#111827`, border `1px solid #1E293B`, text `#94A3B8` in `code-sm`.
- **Specialized Badges (AI/ML & Python highlights):** Background `rgba(59, 130, 246, 0.1)`, border `1px solid rgba(59, 130, 246, 0.3)`, text `#60A5FA`.

### Project Cards
- **Structure:** Two-tiered layout featuring a metadata header (commit date, stack tags, status indicator), a narrative section (problem, implementation, quantified impact), and a bottom action dock (GitHub, live demo, architecture schema).
- **Surface:** Solid `#111827` with `1px solid #1E293B`.
- **Interaction:** Hover state shifts border color to `#334155` and gently shifts the accent title color to `#60A5FA`.

### Form Fields (Contact Section)
- **Input & Textarea:** Background `#0B0F19`, `1px solid #1E293B`, `8px` padding, text `#F8FAFC` in `Inter`, placeholder in `#64748B`.
- **Focus State:** Border shifts cleanly to `#3B82F6` accompanied by an unobtrusive `0 0 0 1px #3B82F6` ring; no heavy colored blurs.

### Status Indicators & Availability Callout
- **"What I'm Seeking" Block:** Employs a dedicated badge featuring a pulsating terminal-green dot (`#10B981`) paired with `label-sm` text specifying current internship or research availability terms.
